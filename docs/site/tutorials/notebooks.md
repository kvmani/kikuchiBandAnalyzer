# Notebook Tutorials

The repository includes two notebook tutorials:

- `docs/notebooks/single_pattern_debug_workflow.ipynb`
- `docs/notebooks/end_to_end_scan_workflow.ipynb`

They follow the same narrative as the Sphinx tutorials but are intended for
interactive local exploration. Notebook execution is disabled during the Sphinx
build so documentation generation remains deterministic and fast.

When updating a notebook, update the corresponding Sphinx tutorial page in the
same change so the web documentation remains the authoritative entry point.
